🦷 Dentalware

Fractal Dentalware es una plataforma web integral diseñada para la gestión clínica y administrativa de consultas odontológicas independientes. Este proyecto nace para solucionar la falta de herramientas centralizadas en el sector, permitiendo al odontólogo asumir el control total de su operación —desde la agenda hasta las finanzas— sin depender de personal administrativo adicional.

🚀 Propuesta de Valor

Autonomía Operativa: Diseñado para optimizar el flujo de trabajo de clínicas unipersonales.

Gestión Centralizada: Integra agenda inteligente, ficha clínica digital, consentimientos informados y reportes financieros en un solo lugar.

Accesibilidad Total: Arquitectura web responsiva que permite el acceso seguro desde cualquier dispositivo y ubicación.

🛠️ Metodología y Desarrollo

El proyecto se ejecuta bajo una adaptación de Scrum ("Solo Scrum") con ciclos de sprints semanales, combinando roles técnicos y de negocio:

Gestión Técnica (Scrum Master/Dev): Enfoque en arquitectura de software robusta, modelado de datos escalable y buenas prácticas de codificación.

Validación de Negocio (Product Owner): Colaboración directa con un socio estratégico del rubro dental
